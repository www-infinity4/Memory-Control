## End-of-life memory flash: evidence-first investigation

### What is currently supported by evidence
- A 2022 case study reported increased gamma activity around cardiac arrest, consistent with neural patterns linked to memory processing.
- Near-death reports often include "life review" experiences, but subjective reports do not by themselves prove a specific storage mechanism.
- Current neuroscience supports memory as distributed brain-network activity (hippocampus + cortex), not a confirmed external storage medium.

### Core research questions for this project
1. Do end-of-life gamma bursts resemble known recall signatures in living brains?
2. Is the "life flash" sequential replay, compressed reconstruction, or a mixed pattern?
3. Are there measurable non-classical (quantum) effects beyond known neural dynamics?
4. Can any external-field or hydrogen-coupling hypothesis be tested and falsified with instrumentation?

### Working model boundaries (to avoid non-testable claims)
- **Supported baseline:** memory recall is generated by neural circuits, oscillations, and synaptic dynamics.
- **Open but unproven:** unusual coupling effects during extreme physiology.
- **Not established:** memories stored in space, brain "ringing up hydrogen" to pull memory packets, or magnetic extraction from an external balloon-like store.

### Testable investigation tracks
- **Neural replay track:** compare gamma/theta coupling near death vs. deliberate autobiographical recall datasets.
- **Compression track:** quantify whether recalled content is temporally compressed vs. chronological.
- **Quantum/null track:** pre-register quantum-related predictions (coherence windows, signatures) and compare against classical models.
- **Hydrogen hypothesis track:** if pursued, define measurable variables (field strengths, spectroscopy, timing) and require blinded controls and replication.

- Prioritize models that produce measurable predictions over purely metaphoric descriptions.
